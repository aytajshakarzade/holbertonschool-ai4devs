# Bug Descriptions

## Bug 1 — bug1.py
- **Intended Behavior:** Calculate the average of a list of numbers.
- **Issue Type:** Runtime Error.
- **Problem:** Division by zero occurs when the list is empty.

## Bug 2 — bug2.js
- **Intended Behavior:** Return the names of all users.
- **Issue Type:** Off-by-One Error.
- **Problem:** The loop accesses an array index outside its valid range.

## Bug 3 — bug3.py
- **Intended Behavior:** Calculate a product's price after a percentage discount.
- **Issue Type:** Logical Error.
- **Problem:** The discount value is subtracted directly instead of being calculated as a percentage.

## Bug 4 — bug4.js
- **Intended Behavior:** Calculate the total and average of product prices.
- **Issue Type:** Data Type Misuse.
- **Problem:** Prices are stored as strings, causing incorrect addition.

## Bug 5 — bug5.py
- **Intended Behavior:** Find the maximum number in a list.
- **Issue Type:** Syntax Error.
- **Problem:** The if statement is missing a colon.

## Bug 6 — bug6.c
- **Intended Behavior:** Calculate the sum of all elements in an integer array.
- **Issue Type:** Off-by-One Error.
- **Problem:** The loop accesses an array element outside its valid range.

## Summary
The five snippets cover runtime, off-by-one, logical, data type, and syntax errors.
