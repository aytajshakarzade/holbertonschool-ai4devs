# User Stories – FocusFlow

## User Story 1
As a user, I want to create an account so that I can manage my personal tasks.

## User Story 2
As a user, I want to log in so that I can access my tasks securely.

## User Story 3
As a user, I want to create new tasks so that I can organize my daily activities.

## User Story 4
As a user, I want to edit or delete tasks so that I can keep my task list updated.

## User Story 5
As a user, I want to set task priorities so that I can focus on important work first.

## User Story 6
As a user, I want to add deadlines to tasks so that I can manage my time better.

## User Story 7
As a user, I want to mark tasks as completed so that I can track my progress.

## User Story 8
As a user, I want AI suggestions for organizing my tasks so that I can work more efficiently.

## User Story 9
As a user, I want to view my productivity statistics so that I can understand my progress.

## User Story 10
As a user, I want to organize tasks into categories so that I can keep everything structured.
