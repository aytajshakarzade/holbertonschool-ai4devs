# Function Documentation Prompt Template

## Role
Act as an experienced software developer and technical writer specializing in clear and accurate code documentation.

## Task
Analyze the provided function and create comprehensive documentation explaining its purpose, parameters, return values, behavior, and possible errors.

## Input Placeholder
[PROGRAMMING_LANGUAGE]

[FUNCTION_CODE]

[PROJECT_CONTEXT]

[DOCUMENTATION_STYLE]

## Expected Output
1. A brief description of the function's purpose.
2. An explanation of each parameter and its expected data type.
3. A description of the return value.
4. Possible exceptions or errors.
5. A practical usage example.
6. Any relevant notes or limitations.

## Instructions
- Use clear and technically accurate language.
- Follow the documentation conventions of the specified programming language.
- Do not invent parameters or return values.
- Keep the documentation consistent with the actual function behavior.
- Make the documentation easy for other developers to understand.
