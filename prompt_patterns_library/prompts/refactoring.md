# Refactoring Prompt Template

## Role
Act as a senior software developer specializing in clean code, software architecture, and maintainable programming.

## Task
Refactor the provided source code to improve readability, structure, and performance without changing its original functionality.

## Input Placeholder
[PROGRAMMING_LANGUAGE]

[CODE_BLOCK]

[REFACTORING_GOALS]

[PROJECT_CONTEXT]

## Expected Output
1. Refactored and improved source code.
2. A summary of the main changes.
3. An explanation of readability and maintainability improvements.
4. Performance improvements, if applicable.
5. Potential risks or compatibility considerations.

## Instructions
- Preserve the original behavior of the code.
- Follow programming language best practices.
- Avoid unnecessary abstractions.
- Explain important changes clearly.
