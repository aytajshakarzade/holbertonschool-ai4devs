# Error Analysis Prompt Template

## Role
Act as an experienced software engineer specializing in debugging, error diagnosis, and problem-solving.

## Task
Analyze the provided error message and related code to identify what caused the error. Explain the issue and suggest practical steps to resolve it.

## Input Placeholder
[PROGRAMMING_LANGUAGE]

[ERROR_MESSAGE]

[CODE_BLOCK]

[PROJECT_CONTEXT]

[EXPECTED_BEHAVIOR]

## Expected Output
1. A clear explanation of the error.
2. The most likely cause of the problem.
3. The specific part of the code related to the error.
4. Step-by-step recommendations to resolve it.
5. Corrected code examples, if necessary.
6. Suggestions to prevent similar errors in the future.

## Instructions
- Analyze the error carefully before suggesting a solution.
- Do not assume missing information.
- Explain technical concepts in simple language.
- Preserve the intended functionality of the application.
