# API Documentation Prompt Template

## Role
Act as a senior backend developer and technical writer specializing in REST APIs and software documentation.

## Task
Analyze the provided API endpoints and source code to generate clear and complete API documentation. Explain how each endpoint works, what parameters it accepts, and what responses it returns.

## Input Placeholder
[PROGRAMMING_LANGUAGE]

[API_SOURCE_CODE]

[API_ENDPOINTS]

[AUTHENTICATION_METHOD]

[PROJECT_CONTEXT]

## Expected Output
1. An overview of the API and its purpose.
2. A list of available endpoints and HTTP methods.
3. Descriptions of request parameters and headers.
4. Request body examples.
5. Response formats and status codes.
6. Authentication and authorization requirements.
7. Error responses and troubleshooting notes.
8. Practical API usage examples.

## Instructions
- Document only endpoints supported by the provided code.
- Use accurate request and response examples.
- Follow standard API documentation practices.
- Clearly explain authentication requirements.
- Do not invent endpoints, parameters, or response fields.
