# README Generation Prompt Template

## Role
Act as a professional technical writer and senior software developer experienced in creating clear and informative project documentation.

## Task
Analyze the provided project files and generate a comprehensive README.md file that explains the project's purpose, features, installation process, configuration, usage, and contribution guidelines.

## Input Placeholder
[PROJECT_NAME]

[PROJECT_DESCRIPTION]

[PROJECT_FILES]

[TECHNOLOGIES_USED]

[INSTALLATION_REQUIREMENTS]

[CONFIGURATION_DETAILS]

## Expected Output
1. Project title and overview.
2. Description of the main features.
3. List of technologies and dependencies.
4. Installation and setup instructions.
5. Configuration instructions.
6. Usage examples.
7. Contribution guidelines.
8. License information, if provided.

## Instructions
- Base the documentation on the supplied project information.
- Do not invent features, dependencies, or configuration values.
- Use clear headings and organized Markdown formatting.
- Include practical code examples where appropriate.
- Make the README easy for new developers to follow.
