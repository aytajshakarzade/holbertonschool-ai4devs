# Root Cause Analysis Prompt Template

## Role
Act as a senior software engineer specializing in system debugging, troubleshooting, and root cause analysis.

## Task
Investigate the provided software issue to determine its underlying cause. Analyze the symptoms, error messages, source code, and system behavior to identify why the problem occurred.

## Input Placeholder
[PROGRAMMING_LANGUAGE]

[CODE_BLOCK]

[PROBLEM_DESCRIPTION]

[ERROR_LOGS]

[PROJECT_CONTEXT]

[EXPECTED_BEHAVIOR]

## Expected Output
1. A clear description of the reported problem.
2. Identification of the root cause.
3. An explanation of the factors contributing to the issue.
4. Relevant code sections or system components involved.
5. Recommended corrective actions.
6. Preventive measures to avoid similar problems.
7. A concise summary of the findings.

## Instructions
- Distinguish the root cause from visible symptoms.
- Support conclusions with evidence from the provided information.
- Do not make unsupported assumptions.
- Explain technical findings clearly.
- Prioritize long-term solutions over temporary workarounds.
