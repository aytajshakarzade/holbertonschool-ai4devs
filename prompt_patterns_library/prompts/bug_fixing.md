# Bug Fixing Prompt Template

## Role
Act as a senior software engineer with expertise in debugging, troubleshooting, and fixing software defects.

## Task
Examine the provided source code, identify the bugs, and implement appropriate fixes while preserving the intended functionality of the application.

## Input Placeholder
[PROGRAMMING_LANGUAGE]

[CODE_BLOCK]

[BUG_DESCRIPTION]

[ERROR_MESSAGE]

[PROJECT_CONTEXT]

## Expected Output
1. A description of each identified bug.
2. An explanation of the cause of each bug.
3. Corrected source code.
4. A summary of the changes made.
5. Steps to verify that the fixes work.
6. Recommendations to prevent similar bugs.

## Instructions
- Focus on fixing the actual cause of each bug.
- Avoid unrelated code changes.
- Preserve existing functionality.
- Explain each fix clearly.
- Do not invent errors that are not supported by the provided information.
