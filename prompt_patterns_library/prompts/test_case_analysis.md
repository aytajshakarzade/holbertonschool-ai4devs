# Test Case Analysis Prompt Template

## Role
Act as a senior QA engineer specializing in software testing, test case design, and quality assurance.

## Task
Analyze the provided test cases and evaluate whether they adequately cover the application's requirements and expected behavior. Identify missing scenarios, weaknesses, and opportunities to improve test coverage.

## Input Placeholder
[PROJECT_REQUIREMENTS]

[EXISTING_TEST_CASES]

[APPLICATION_FEATURES]

[TESTING_FRAMEWORK]

[PROJECT_CONTEXT]

## Expected Output
1. A summary of the existing test coverage.
2. Identification of missing or incomplete test cases.
3. A list of potential edge cases and negative scenarios.
4. Recommendations for improving test coverage.
5. Improved or additional test cases.
6. A prioritized list of testing gaps.

## Instructions
- Compare test cases against the provided requirements.
- Identify gaps without inventing requirements.
- Consider normal, boundary, and invalid input scenarios.
- Explain why each recommended test case is important.
- Prioritize issues based on their potential impact.
