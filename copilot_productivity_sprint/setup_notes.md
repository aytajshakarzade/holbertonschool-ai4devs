# Copilot Productivity Sprint – Setup Notes

## 1. Development Environment

For this project, I am using the following development environment:

- Operating System: Windows 11
- Code Editor: Visual Studio Code
- Version Control: Git
- Repository Hosting: GitHub

## 2. GitHub Copilot

I selected GitHub Copilot as the AI coding assistant for this sprint.

The extensions used in Visual Studio Code are:

- GitHub Copilot
- GitHub Copilot Chat

Copilot will be used to get code suggestions, complete functions, understand errors, and generate code when needed.

## 3. Installation Process

I prepared the development environment by following these steps:

1. Installed and opened Visual Studio Code.
2. Opened the Extensions Marketplace.
3. Searched for GitHub Copilot.
4. Installed the official extension.
5. Installed GitHub Copilot Chat.
6. Signed in to my GitHub account.
7. Completed the authorization process.
8. Checked that Copilot was available in the editor.

## 4. Account and Requirements

A GitHub account is required to use Copilot.

The account must have access to GitHub Copilot through an eligible plan. An internet connection is also needed for authentication and AI features.

## 5. Version Information

I use the following commands to check the installed versions:

**Visual Studio Code:**
```bash
code --version
```

**Git:**
```bash
git --version
```

**VS Code extensions:**
```bash
code --list-extensions --show-versions
```

The output of these commands can be used to record the exact versions of the tools and extensions used during the experiment.

## 6. Productivity Tools

For tracking the results, I plan to use:

- Stopwatch to measure how long each task takes.
- Git to keep track of code changes.
- Unit tests to check whether the solutions work correctly.
- Lines of code to compare the size of each implementation.

## 7. How I Will Run the Experiment

I will solve each programming task in two different ways.

**First attempt – Without Copilot**

I will write the solution myself without using AI assistance. I will record the time, test the result, and note any problems I encounter.

**Second attempt – With Copilot**

I will solve the same task using GitHub Copilot. I will record the same information and use the same tests as in the first attempt.

This will help me compare both approaches under similar conditions.

## 8. What I Will Compare

After completing the tasks, I will compare:

- Time spent on each task.
- Amount of code written.
- Number of tests passed.
- Errors and fixes required.
- Overall code quality.
