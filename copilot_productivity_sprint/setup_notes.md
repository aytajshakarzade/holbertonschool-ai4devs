# Setup Notes – Copilot Productivity Sprint

## 1. Development Environment

- **IDE:** Visual Studio Code
- **Operating System:** Windows 11
- **Version Control:** Git
- **Repository Hosting:** GitHub

## 2. AI Coding Assistant

- **Tool:** GitHub Copilot
- **Extension:** GitHub Copilot for Visual Studio Code
- **Purpose:** AI-assisted code completion, code generation, and programming support.

## 3. Setup Steps

1. Installed Visual Studio Code.
2. Opened the Extensions Marketplace.
3. Searched for the GitHub Copilot extension.
4. Installed the extension.
5. Signed in using a GitHub account.
6. Verified that the extension was enabled and available in the editor.

## 4. Productivity Measurement Tools

The following tools will be used during the sprint:

- **Stopwatch:** To measure task completion time.
- **Git:** To track code changes.
- **Testing tools:** To verify code correctness and quality.

## 5. Sprint Methodology

Each benchmark task will be completed twice:

1. Without AI assistance.
2. With GitHub Copilot assistance.

The results will be compared based on completion time, code quality, and lines of code.

## 6. Conclusion

This environment is prepared for conducting a controlled comparison between traditional programming and AI-assisted development.
